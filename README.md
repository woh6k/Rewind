# Rewind / 还真

> Minecraft Forge 1.20.1 的世界快照与回档模组。

**当前版本：1.0.0**  
适用版本：Minecraft 1.20.1 
Mod ID：`rewind` · 作者：woh6k

还真会为世界创建完整文件快照。回档时先正常关闭服务端，再通过原版世界加载流程打开目标世界，因此不会直接覆盖正在运行的世界文件。

## 功能

- 每个世界独立保存 3 个自动存档槽和 5 个手动存档槽。
- 自动存档默认每 10 分钟执行一次，按时间淘汰最旧快照。
- K 打开存档管理界面；支持滚轮浏览、默认保存／读取槽、自动间隔调节和长按加减。
- F6 保存默认手动槽；F7 请求读取默认读取槽。
- 手动快照支持备注：`/rewind commit 2 "主基地完工"`。
- 回档前需要管理员二次确认，普通玩家只收到提示并随服务端重连。
- K 界面可手动清理回档后遗留的旧世界副本，保留最近一次安全备份。

## 安装

将同一版本的 Rewind jar 放入以下位置：

- 单人：你的客户端 `mods` 目录。
- 联机：房主和每位加入者的 `mods` 目录。
- 专用服务器：服务端和每位客户端的 `mods` 目录。

客户端与服务端必须使用同一版本。

## 使用

| 操作     | 默认方式                             |
|--------|----------------------------------|
| 按键部分   | `快捷键`                            |
| 打开管理界面 | `K`                              |
| 快速保存   | `F6`                             |
| 快速读取   | `F7`                             |
| 指令部分   | `/`                              |
| 命名保存   | `/rewind commit <1-5> "备注"`      |
| 确认覆盖   | `/rewind Y`                      |
| 取消覆盖   | `/rewind N`                      |
| 强制覆盖   | `/rewind sudo commit <1-5> "备注"` |

`commit` 只允许手动槽 1–5。名称为空或省略时，快照显示为默认的保存时间。自定义名称只是 GUI 备注；磁盘文件夹仍使用安全的 ASCII 槽位和时间名称。

## 权限与联机

- 单人世界房主可操作，无需开启作弊。
- 专用服务器要求 OP 4。
- LAN 客人需要明确的 OP 4 权限；“允许所有玩家作弊”不会授予还真管理权限。
- 管理员确认回档后，所有玩家会在 5 秒后断开。
- 专用服务器需要由管理员、面板或启动脚本重新启动；单人会自动通过原版入口重新打开世界；LAN 房主需要重新开放局域网。

## 存储与清理

快照由服务端管理，单人和 联机 则由房主的集成服务端管理。每个世界的文件位于：

```text
rewind/
└─ worlds/
   └─ world-<UUID>/
      ├─ auto/
      ├─ manual/
      ├─ recovery/
      │  ├─ last_restore_backup/
      │  └─ displaced-<UUID>/
      └─ settings.json
```

`last_restore_backup` 是最近一次回档前的安全备份。`displaced-*` 是成功回档后留下的旧世界副本；确认不需要恢复后，可在 K 界面点击“清理缓存”并二次确认。该操作不可撤销，未完成回档时会被拒绝。

## 注意事项

- 第一次用于正式世界前，请先复制备份整个世界文件夹。
- 大世界或慢硬盘可能让保存明显卡顿。快照复制超过约 20 秒会取消提交，原快照保持不变。
- 使用自行异步写入世界文件的第三方模组时，需要先在测试世界验证兼容性。
- 不要在回档失败后手动删除 `rewind/pending`、`recovery` 或安全备份；保留它们以便下次启动恢复。
